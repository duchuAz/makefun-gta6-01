# PALMA VISTA

PALMA VISTA is an original third-person open-world crime game built for make.fun's [gta6-01 bounty](https://make.fun). Explore a sunlit island city on foot or behind the wheel, take on jobs, and make a name for yourself — all rendered in real time in the browser.

**Controls:** WASD to move, mouse to look/aim, Shift to sprint, Space to jump, E to interact, R to reload, F for the horn, 1–3 to switch weapons, M for the map, Esc/P to pause.

```bash
node serve.ts
```
